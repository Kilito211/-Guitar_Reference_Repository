## 📖 项目简介
这个仓库是我个人整理的吉他学习资料汇总，涵盖了从基础理论、乐谱到进阶技巧的方方面面。旨在为自己提供一个云端备份，同时也分享给所有热爱吉他的朋友。

## 🚀 如何使用这些资料
1. **在线浏览**：直接点击上方目录中的文件夹进行查看。
2. **本地下载**：
   - 点击仓库右上角的 `克隆/下载` 按钮。
   - 或者使用 Git 命令：
     ```bash
     git clone https://gitee.com/Kilito_hyx/git_guitar.git
     ```
3. **推荐工具**：
   - 查看 `.gp` 文件建议使用：[Guitar Pro](https://www.guitar-pro.com/) 或 [TuxGuitar](http://tuxguitar.com.ar/) (开源免费)。
   - 查看 `.md` 文档建议使用：[Typora](https://typora.io/) 或 VS Code。
